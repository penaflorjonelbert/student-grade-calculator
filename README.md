# Student Grade Calculator

A simple Student Grade Calculator made using HTML, CSS, and JavaScript.

## Features

- Enter Quiz Score
- Enter Exam Score
- Enter MCO Score
- Calculate Final Grade

## Grade Formula

Quiz = 20%

Exam = 30%

MCO = 50%

Final Grade = Quiz + Exam + MCO

## Technologies Used

- HTML
- CSS
- JavaScript
